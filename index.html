Fitur Unggulan Sistem

  • Manajemen Penduduk (CRUD): Tambah, edit, dan hapus data warga secara instan.
  • Pencarian KMP & Boyer-Moore: Pencarian string presisi tinggi dengan milidetik response time.
  • Chatbot CIPABOT Interaktif: Chatbot floating terintegrasi di portal web.
  • Ekspor Laporan (Excel & PDF): Cetak rekapitulasi data warga siap pakai.

Petunjuk Penggunaan

Panduan Operasional Portal SiWarga

Petunjuk bagi petugas Kelurahan Cipaganti dan Pengurus RW 02 dalam mengoperasikan sistem.

1. Pantau Dashboard

Lihat ringkasan statistik kependudukan, total KK, dan demografi gender warga secara otomatis.

2. Kelola Data Warga (CRUD)

Tambah warga baru, edit profil warga, hapus data, dan lakukan filter RT/RW dengan cepat.

3. Manfaatkan CIPABOT Widget

Klik ikon melayang CIPABOT di pojok kanan bawah untuk mencari data warga melalui percakapan AI.

4. Unduh Laporan

Cetak laporan data warga ke dalam format Excel (.xlsx) atau PDF siap pakai untuk keperluan administratif.

Sistem ini dikembangkan sebagai Tugas Akhir / Skripsi dengan fokus penelitian pada perbandingan performa algoritma Knuth-Morris-Pratt (KMP) dan Boyer-Moore dalam konteks pencarian data kependudukan.

Teknologi & Algoritma yang Digunakan

HTML5 / CSS3 / JavaScript

Pengembangan Frontend murni tanpa framework, membuktikan efisiensi algoritma tanpa overhead library.

Knuth-Morris-Pratt (KMP)

Algoritma pencocokan string dengan preprocessing LPS (Longest Prefix Suffix) berkompleksitas O(n + m).

Boyer-Moore

Algoritma pencarian dengan heuristik Bad Character & Good Suffix. Unggul pada pola panjang dan teks besar.

Dataset Excel & JSON

Data warga dalam format Excel (.xlsx) dapat diunggah langsung ke chatbot untuk pengujian real-world.
